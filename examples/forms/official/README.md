# Official forms (not under the MIT licence)

Blank forms of German authorities, kept here as test input for A4Norm Forms.
Each file is exactly as the authority publishes it, byte for byte (§ 62 UrhG);
`../official.py` checks every one against its sha256.

**amtliches Werk, § 5 Abs. 2 UrhG, aus öffentlichen Quellen für Tests heruntergeladen,
nicht unter der MIT-Lizenz.** The rights, and the duty to name the source (§ 63 UrhG), stay with
each authority below. None of them carries a form publisher's (Formularverlag) imprint or
"Nachdruck verboten"; a form that does stays a link in `../official.json` and is not put here.
